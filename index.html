Simulation Instructions

Mission workflow

  1. Read the ticket and inspect the visual.
  2. Use the interactive Wireless Field Guide to search, expand topics, and reveal key-term coaching.
  3. Select one answer and submit it.
  4. If incorrect, investigate the recommended guide topic and retry.
  5. After a correct response, use “Review This in the Field Guide” to connect the answer to supporting evidence.
  6. Each mission awards one point only once.

Guide mastery

Each guide topic reports how many related missions are resolved. “Review weak topics” filters out mastered sections. These study indicators do not add or remove points.

Keyboard access

Use Tab to move between controls. Use arrow keys within radio-button answers. Press Space to select and Enter to activate buttons and expandable guide sections.

Plain-text instructions

Complete all 30 wireless support missions. Each mission contains one question worth one point. Incorrect answers can be retried. Points cannot be earned twice. The activity is complete after every mission is answered correctly. The final screen displays your name, score, percentage, completion status, and total attempts for a Canvas screenshot.

Modernizations applied

  • 5G is presented as using both sub-6 GHz and, in some deployments, millimeter-wave spectrum—not millimeter wave alone.
  • 802.11 advertised rates are treated as theoretical maximums, not guaranteed user throughput or range.
  • WPA2 is taught with AES-CCMP as the secure baseline; legacy TKIP compatibility is not presented as a recommended configuration.
  • A PSK is described as a shared credential used for authentication and key derivation, not as an encryption algorithm.
  • WPA2/WPA3-Enterprise behavior depends on the selected EAP method; certificates are required for EAP-TLS but not identically for every EAP method.
  • Hidden SSIDs and MAC filtering are identified as weak controls, not substitutes for modern encryption and authentication.
